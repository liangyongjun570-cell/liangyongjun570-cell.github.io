## 快速开始

你可以通过编辑 `source/_posts/` 目录下的文件来创建新文章。

### 常用命令

```bash
hexo new "文章标题"    # 新建文章
hexo generate          # 生成静态文件
hexo server            # 启动本地服务
hexo deploy            # 部署到远程
```
